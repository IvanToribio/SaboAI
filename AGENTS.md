## Agent skills

### Issue tracker

Las tareas y especificaciones se guardan en Markdown local. Antes de crear, consultar o actualizar tareas, lee `docs/agents/issue-tracker.md`.

### Triage labels

Se usan los cinco estados predeterminados. Antes de clasificar una tarea o cambiar su estado, lee `docs/agents/triage-labels.md`.

### Domain docs

Estructura single-context: `GLOSSARY.md` y `docs/adr/` en la raíz. Antes de explorar el proyecto, lee `docs/agents/domain.md`.

## Código sencillo y explicable

Al escribir o modificar código, elige la solución más sencilla que cumpla los requisitos. Usa nombres claros, organiza el flujo para que Iván pueda seguirlo y explicarlo, y añade abstracciones solo cuando faciliten la lectura o el mantenimiento.

Conserva la lógica necesaria para que el código funcione correctamente. Antes de entregar, comprueba el flujo principal y los casos límite en los que un fallo tendría consecuencias graves.
